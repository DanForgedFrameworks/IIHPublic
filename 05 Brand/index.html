What each logo is, which one to use, and how to save it.

Start here

There are three logos. They are the same identity in three shapes, for three different amounts of space. Pick by the shape of the gap you are filling.

Wide space?

Use the horizontal lockup. Page headers, letterheads, email footers.

Square or round space?

Use the emblem. Social profile pictures, stamps, badges.

Tiny space?

Use the brandmark. Favicons, app icons, avatars.

If you only remember one thing

Download the SVG if the thing you are using accepts it — it stays sharp at any size. If it will not accept an SVG, download a PNG and pick a size a little larger than you need.

How to save a file

On a computer

  1. Click the button for the size you want. Most browsers save it straight to your Downloads folder.
  2. If it opens in the browser instead of saving, press Ctrl + S (Windows) or Cmd + S (Mac).
  3. Do not rename the file. The name records which logo it is and what version, which is how we keep track of them.

On a phone or tablet

  1. Press and hold the logo image above.
  2. Choose Save to Photos, Download image, or Share.

Putting it into Word, PowerPoint or Canva

  1. Save the file first using the steps above.
  2. In your document use Insert → Picture → This device and choose the file you saved.
  3. To resize it, drag a corner handle, never a side handle — a side handle squashes the logo out of shape.

If the logo appears with a white box around it

You have probably saved a screenshot of it rather than the file itself. Go back and use the download buttons — those files have a transparent background and will sit on any colour.

Social media sites nearly always reject SVG. For a profile picture, use Emblem 512.

Animated versions

Use the Play animation button on the lockup or emblem above to watch one. They are for live web pages only, and they stop completely for anyone who has reduced motion turned on in their device settings.

There is no animated file for documents or slides

We tested one and removed it, because it came out half-drawn in Word, PowerPoint and file previews. For anything that is not a live web page, use a normal PNG or SVG. A logo that does not move is never wrong.

Colours

These are the logo's own colours. They are close to, but not the same as, the colours used in the IIH UK digital leaflets — do not swap one set for the other.

#65C6B3 symbol and “UK” #628CC5 “II” and “H” #1A2B4A emblem ring #D4730A web and email text

Please don't

  • Stretch, squash or rotate the logo — always drag a corner handle
  • Change the colours, or add shadows, outlines or effects
  • Rebuild the lockup yourself by placing the symbol next to the letters — use the supplied file
  • Place it on a busy photograph, or on a colour close to the teal
  • Use it in a way that suggests IIH UK endorses something it has not
